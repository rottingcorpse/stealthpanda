# Reporting security issues

> ## StealthPanda fork notice
>
> **This repository is a downstream fork** of
> [lightpanda-io/browser](https://github.com/lightpanda-io/browser).
> Security vulnerabilities in the browser engine belong **upstream**:
> report them privately to the Lightpanda project as described below —
> **not** in this repository, and **not** in this fork's public issue
> tracker.
>
> Only vulnerabilities specific to this fork's stealth layer (files under
> `src/stealth/` or the `// STEALTHPANDA`-marked hooks) should be reported
> against this repository — please use GitHub's private vulnerability
> reporting on this repo for those.

## Supported Versions

Security fixes are applied to the latest `main` branch.

## Reporting a Vulnerability

Please **DO NOT** file a public issue, instead send your report privately to security@lightpanda.io.

Security reports are greatly appreciated and we will publicly thank you for it, although we keep your name confidential if you request it.
